API RESPONSE FORMATS:
=====================

I. LIVE TIMING API - GET /events
---------------------------------
Returns list of live events with abbreviated field names.

Response Structure:
{
  "LiveEvents": [
    {
      "id": string,              // Event ID (e.g., "QMJLNRVR-2147484360")
      "n": string,               // Event name
      "pyt": number,             // Payment type (0=free, 2=paid, etc.)
      "s": number,               // Status (100=scheduled, 101=practice, 102=active, 104=completed, 107=cancelled)
      "f": number,               // Sport/Format (0=general, 3=karting, 4=motorcycles, etc.)
      "dt": string,              // Date/time (format: "DD-MM-YYYY HH:mm:ss.SSS")
      "l": {                     // Location object
        "c": string,             // Country name
        "cc": string,            // Country code (ISO 2-letter)
        "ct": string,            // City/region
        "lat": number,           // Latitude (optional)
        "lon": number            // Longitude (optional)
      },
      "u": string,               // User/organizer email
      "ov": string,              // Orbits version (timing software)
      "t": {                     // Track object
        "id": string,            // Track ID
        "n": string,             // Track name
        "l": number,             // Track length
        "um": string             // Unit of measure ("km" or "mi")
      },
      "w": {                     // Weather object (optional, only if available)
        "t": number,             // Temperature
        "ts": string,            // Timestamp
        "pi": number,            // Precipitation
        "pp": number,            // Precipitation probability
        "ty": number             // Weather type
      }
    }
  ]
}

Status Codes:
- 100: Scheduled (not started)
- 101: Practice/Testing
- 102: Active (live timing available)
- 104: Completed
- 107: Cancelled

Sport Codes:
- 0: General/Unspecified
- 3: Karting
- 4: Motorcycles/Motocross
- (other codes vary by discipline)

III. LIVE TIMING API - GET /events/{eventId}/sessions/{sessionId}/data
-----------------------------------------------------------------------
Returns session data with leaderboard (NOT just "competitors").

Response Structure:
{
  "id": string,                  // Session ID
  "l": [                         // Leaderboard array (NOT 'c' for competitors!)
    {
      "id": number,              // Competitor ID
      "no": string,              // Number (car/kart/bike number)
      "nam": string,             // Name
      "btTm": string,            // Best Time (format: "M:SS.mmm")
      "ls": number,              // Laps completed
      "pos": number,             // Overall position
      "cl": string,              // Class/category
      "pCl": number,             // Position in class
      "btCl": boolean,           // Is best time in class
      "gp": string,              // Gap to competitor IN FRONT (previous position)
      "df": string,              // Total gap/difference to LEADER (P1)
      "gpCl": string,            // Gap to class leader
      "dfCl": string,            // Difference to previous in class
      "lbpos": number            // Last best position
    }
  ]
}

Gap Field Explanation:
- "gp" (Gap) = Gap to the competitor IN FRONT (previous position)
- "df" (Difference) = Total gap to the LEADER (P1)
- To get gap BEHIND: Use the next position's "gp" field
  Example: For P2, gap behind = P3's "gp" value

Real Example from Session:
- P2: gp = "2 Laps" (2 laps behind P1), df = "2 Laps" (2 laps to leader)
- P3: gp = "17 Laps" (17 laps behind P2), df = "19 Laps" (19 laps to leader)


IV. LIVE TIMING API - GET /events/{eventId}/sessions/{sessionId}/competitor/{competitorId}
-------------------------------------------------------------------------------------------
Returns detailed lap-by-lap data for specific competitor.

Response Structure:
{
  "results": [                   // Array of lap results (one per lap)
    {
      "id": number,              // Competitor ID
      "ibt": false,              // Is Best Time flag (true for best lap)
      "btCl": false,             // Best Time in Class flag
      "gp": 5.680,               // Gap to leader (seconds)
      "df": 6.486,               // Difference to previous (seconds)
      "gpCl": 5.680,             // Gap to class leader
      "dfCl": 6.486,             // Difference to previous in class
      "lsTm": "1:35.485",        // Lap Time for this lap (format: "M:SS.mmm")
      "ls": 1,                   // Lap number
      "lbpos": 0,                // Last best position
      "pCl": 3,                  // Position in class
      "pos": 3,                  // Overall position at this lap
      "cl": "SUPERBIKE"          // Class/category
    },
    ... (one entry per lap)
    {
      "id": 16506829,
      "ibt": true,               // ⭐ Best lap marked with ibt: true
      "btCl": false,
      "gp": 0.000,
      "df": 0.000,
      "lsTm": "1:27.697",        // This lap's time (also the best)
      "ls": 19,                  // Lap number
      "btTm": "1:27.697",        // Best Time overall (only in last/summary entry)
      "btLp": 19,                // Best Lap number (only in last/summary entry)
      "nam": "MLUNGO",           // Name (only in last/summary entry)
      "no": "88",                // Number (only in last/summary entry)
      "pos": 1,                  // Final position
      "cl": "SUPERBIKE"
    }
  ]
}

Structure Notes:
- Each lap is a separate entry in 'results' array
- The lap with 'ibt: true' is the best lap
- The LAST entry contains summary data:
  - 'nam' (name), 'no' (number) fields
  - 'btTm' (best time), 'btLp' (best lap number)
  - Total laps in 'ls' field
- Position changes throughout race tracked in 'pos' field of each lap
